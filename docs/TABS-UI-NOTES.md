## 2. Реализованный интерфейс и поведение

### Полоса вкладок (`src/ui/TabBar.svelte`)
- Располагается между строкой меню (`.menu-row`) и рабочей областью редактора / плашками уведомлений (`.notice-row`, `main.editor-stage`).
- Каждая вкладка отображает:
  - Имя файла для сохранённых документов (например, `notes.md`).
  - Первые слова текста для безымянного документа с текстом (до 48 символов, вычисляется через `tabLabel(tab)`).
  - Локализованную надпись «Без названия» («Untitled», «Ohne Titel» и т.д.) для пустых безымянных документов.
  - Бейдж формата (`Markdown`, `Plain Text` и т.д.) с локализованной подписью из `formatLabel`.
  - Индивидуальную кнопку закрытия `×` с подсказкой и доступным лейблом `aria-label={t("tabs.closeTab", { name })}`.
- Активная вкладка:
  - Подсвечена фоном `--bg-primary` (сливается с рабочей областью редактора под ней).
  - Имеет акцентный индикатор (`box-shadow: 0 -2px 0 0 var(--accent)`).
  - Текст заголовка выделен полужирным (`font-weight: 500`), цвет `--text-normal`.
  - `aria-selected="true"`, `tabindex="0"`.
- Справа от последней вкладки расположена кнопка «плюс» (`+`):
  - Открывает новую вкладку с чистым состоянием и стартовым экраном (`StartScreen`) для выбора формата или перетаскивания файла.
  - Подсказка: «Новая вкладка (Ctrl+T)» / «New tab (Ctrl+T)».

### Доступность кнопки «плюс» при одной вкладке (обоснование решения)
- **Правило простоты**: согласно контракту, когда открыта всего 1 вкладка, полоса вкладок скрыта, чтобы редактор оставался простым и чистым интерфейсом для работы с одним файлом.
- **Интерфейсное решение**:
  1. **Компактная кнопка «+» в строке управления**: при `workspace.tabs.length < 2` кнопка «+» с пунктирной рамкой в стиле MarkNote размещается в правом верхнем углу строки меню, непосредственно перед элементами сохранения (`.save-controls-overlay`). Она всегда видна и легкодоступна в один клик без загромождения рабочей области.
  2. **Горячая клавиша `Ctrl+T`**: глобально перехватывается в окне приложения и сразу открывает новую вкладку. Как только вкладок становится 2 или более, автоматически отображается полоса вкладок `TabBar.svelte`, а кнопка «+» перемещается на своё каноническое место справа от последней вкладки.
  3. **Закрытие последней вкладки**: закрытие единственной оставшейся вкладки инициирует закрытие окна со стандартным запросом о несохранённых изменениях (`CloseRequested` / `requestClose()`).

## 3. Решение для отображения 10+ открытых вкладок

### Текущее поведение
- Контейнер полосы вкладок использует CSS Flexbox:
  - `flex: 0 1 180px; min-width: 80px; max-width: 200px;`
  - Имя файла сжимается с многоточием (`text-overflow: ellipsis; white-space: nowrap; min-width: 0;`).
  - Бейдж формата и крестик закрытия имеют фиксированную ширину (`flex-shrink: 0`).
  - Контейнер имеет `overflow-x: auto; scrollbar-width: none;` (нативная прокрутка колёсиком мыши без визуального скроллбара).
- При 10 открытых вкладках на экране шириной 1000px–1200px вкладки плавно уменьшаются до ~90–100px, сохраняя читаемость начала имени файла и формата.

### Продуманная архитектура для масштабирования (roadmap/будущие релизы)
1. **Горизонтальная плавная прокрутка полосы**:
   - Обработка `wheel`: наведение курсора на полосу транслирует вертикальную прокрутку колёсика мыши в горизонтальный сдвиг (`scrollLeft += event.deltaY`).
   - При переключении вкладок клавиатурой или программно вызывается `tabElement.scrollIntoView({ behavior: 'smooth', block: 'nearest', inline: 'nearest' })`, гарантируя видимость активной вкладки.
2. **Кнопка переполнения (Dropdown Menu)**:
   - При превышении суммарной ширины вкладок над шириной окна справа от кнопки «+» появляется кнопка-шеврон `∨`.
   - Клик по шеврону открывает всплывающее меню с полным списком открытых вкладок, быстрым поиском/фильтром по имени и иконками статуса («грязный» документ, формат).
3. **Минимальный предел сжатия**:
   - `min-width: 100px;` для вкладок с текстом; когда суммарная длина превышает viewport, вкладки больше не сжимаются до нечитаемого состояния, а переходят в горизонтальный скролл-режим.
4. **Закрепление вкладок (Pinned Tabs)**:
   - Закреплённые вкладки сжимаются до одного бейджа формата/иконки и прижимаются к левому краю.
