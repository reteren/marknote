# Дорожная карта

Восемь вех. Порядок важен: каждая опирается на предыдущую. Оценки — в часах
чистой работы для одного разработчика, знакомого с Rust, но не с CodeMirror.

Итог до v1.0: **примерно 166 часов**. Из них треть уходит на веху M2 — это
нормально, живой предпросмотр и есть проект, остальное обвязка.

| Веха | Что получаем | Часы |
| --- | --- | --- |
| M0 | Скелет: окно открывается, файл читается | 6 |
| M1 | Ядро редактора: правка, отмена, перенос строк | 12 |
| M2 | Живой предпросмотр | 45 |
| M3 | Файлы, окна, создание документов, сохранение | 28 |
| M4 | Блочные элементы: таблицы, callout, формулы, картинки | 25 |
| M5 | Обвязка интерфейса: меню, стартовый экран, строка состояния, поиск | 22 |
| M6 | Остальные форматы | 18 |
| M7 | Сборка, ассоциации, релиз | 10 |

**Важно про порядок.** Реестр форматов появляется в M3, а не в M6, — от него
зависят стартовый экран, кнопки сохранения и смена типа документа. В M3 в
реестре лежат два типа, Markdown и простой текст; M6 дописывает остальные
адаптеры. Интерфейс при этом не меняется: он целиком строится из списка,
который отдаёт Rust.

## M0 — Скелет · 6 ч

Цель: `npm run tauri dev` открывает тёмное окно, в котором виден текст файла,
переданного аргументом командной строки.

- [ ] Инициализировать Tauri 2 + Svelte 5 + TypeScript + Vite
- [ ] Подключить `theme.css`, включить тёмный заголовок окна через
      `DWMWA_USE_IMMERSIVE_DARK_MODE`
- [ ] Вставить CodeMirror 6 в чистом виде, без расширений
- [ ] IPC-команда `open_file(path) -> { text, meta }`
- [ ] Прочитать `std::env::args()` при старте и загрузить файл
- [ ] Завести Git, `.gitignore`, первый коммит

**Готово, когда:** `marknote.exe test.md` показывает содержимое файла.

## M1 — Ядро редактора · 12 ч

Цель: в окне можно печатать. Пока сырой Markdown с подсветкой, без скрытия
разметки.

- [ ] `@codemirror/lang-markdown` + подсветка синтаксиса
- [ ] История отмены без ограничений, `Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y`
- [ ] Мягкий перенос: колонка текста `max-width: 81ch`, по центру окна,
      `EditorView.lineWrapping`. Файл на диске не меняется — в него никогда не
      пишутся переносы
- [ ] Поведение `Tab`: внутри списка — вложенность на уровень, `Shift+Tab` —
      обратно; вне списка — четыре пробела
- [ ] `Enter` в списке продолжает список; на пустом пункте — выходит из него
- [ ] Автопарность: `**`, `*`, `` ` ``, `==`, `~~`, `[`, `(`
- [ ] Обёртка выделения: `Ctrl+B`, `Ctrl+I`, `Ctrl+E` (код) оборачивают
      выделенный текст, повторное нажатие снимает обёртку
- [ ] Базовая правка: выделить всё, вырезать, копировать, вставить

**Готово, когда:** файл можно осмысленно редактировать и отменять правки, а
длинные абзацы переносятся по ширине колонки.

## M2 — Живой предпросмотр · 45 ч

Главная веха. Разметка скрыта, пока курсор не внутри узла.

Механика: `ViewPlugin` строит `DecorationSet`. Для каждого узла дерева
`@lezer/markdown` в видимой области решаем — прятать маркеры или показать.
Узел раскрывается, если пересекается с выделением или содержит курсор. При
`selectionSet` декорации пересчитываются только для затронутых строк.

### M2.1 — Каркас · 10 ч
- [ ] `ViewPlugin` с пересчётом на `docChanged` и `selectionSet`
- [ ] Обход `syntaxTree` в пределах `view.visibleRanges`
- [ ] Функция `isNodeActive(node, selection)` — единая точка правды о раскрытии
- [ ] Атомарные диапазоны (`EditorView.atomicRanges`), чтобы стрелка не
      застревала внутри скрытых маркеров

### M2.2 — Строчная разметка · 12 ч
- [ ] `**жирный**`, `*курсив*`, `~~зачёркнутый~~`, `==подсветка==`
- [ ] `` `код` `` — фон и моноширинный шрифт
- [ ] `%%комментарий%%` — приглушённый цвет, целиком скрывается при уходе курсора
- [ ] `$формула$` — inline-KaTeX, при курсоре внутри возвращается исходный текст
- [ ] Вложенность: `**жирный *и курсив* внутри**`
- [ ] Ссылки `[текст](url)`: виден только текст, `Ctrl+клик` открывает в браузере

### M2.3 — Заголовки и списки · 10 ч
- [ ] `#`–`######`: решётки скрыты, размер и вес по уровню
- [ ] Маркированные списки: `-` превращается в буллет, отступы по уровням
- [ ] Нумерованные списки: номер остаётся, точка форматируется
- [ ] Задачи `- [ ]` / `- [x]`: рисуется чекбокс, клик переключает состояние и
      правит документ; выполненные — зачёркнуты и приглушены

### M2.4 — Производительность · 8 ч
- [ ] Тест на файле 10 000 строк: ввод символа не должен давать задержку
      больше 16 мс
- [ ] Профилирование пересчёта декораций, кэш по номеру строки
- [ ] KaTeX рендерится лениво и кэшируется по исходной строке формулы

### M2.5 — Шлифовка · 5 ч
- [ ] Курсор не прыгает при раскрытии и схлопывании разметки
- [ ] Выделение мышью через границу скрытого маркера не рвётся
- [ ] `Home` / `End` / `Ctrl+←` ведут себя как ожидается на скрытых участках

**Готово, когда:** файл с любым сочетанием разметки выглядит как в Obsidian, а
курсор ведёт себя предсказуемо. Это единственная веха, которую стоит проверять
на живых заметках, а не на синтетических примерах.

## M3 — Файлы, окна и сохранение · 28 ч

### M3.1 — Реестр форматов и состояние документа · 5 ч
- [ ] Структура `FormatCapabilities` и реестр типов на стороне Rust
- [ ] Команды `list_creatable_formats`, `new_document`, `format_for_extension`
- [ ] В реестре пока два типа: Markdown и простой текст. Остальные добавит M6
- [ ] `DocumentState` на фронтенде: путь, тип, состояние сохранения
- [ ] `path === null` отключает автосохранение — единая точка правды

### M3.2 — Создание документов · 6 ч
- [ ] Стартовый экран с плитками типов, `Open file…` и подсказкой про
      перетаскивание. Список плиток строится из реестра, а не зашит в разметку
- [ ] Начать печатать, не выбрав тип, — документ создаётся как Markdown
- [ ] Заготовки нового документа по типу: `{}` для JSON, каркас для HTML,
      пусто для остальных
- [ ] Заголовок окна `Untitled.json — MarkNote`
- [ ] `Ctrl+N` и `Ctrl+Shift+N`
- [ ] Смена типа документа без потери текста, пересчёт возможностей

### M3.3 — Сохранение · 7 ч
- [ ] Кнопки `Save` и `Save as…` в правой части строки меню с пометкой
      состояния: `Unsaved`, `Saving…`, `Saved 12:04`, `Read-only`
- [ ] `Save` у документа без пути открывает диалог сохранения
- [ ] `Save as…` с фильтром типов; выбранное расширение задаёт тип документа
- [ ] Автосохранение: 2 секунды простоя, потеря фокуса окна, закрытие окна
- [ ] Атомарная запись: временный файл рядом → `fs::rename`. Никогда не писать
      поверх оригинала напрямую
- [ ] Закрытие окна с непустым несохранённым документом спрашивает
      `Save` / `Discard` / `Cancel`. Единственный такой диалог в программе
- [ ] Перетаскивание файла в окно открывает его

### M3.4 — Окна и диск · 10 ч
- [ ] Наблюдение за диском (`notify`) с подавлением собственных записей
- [ ] Внешнее изменение при чистом буфере — тихая перезагрузка с сохранением
      позиции курсора
- [ ] Внешнее изменение при грязном буфере — полоса сверху: «Файл изменён на
      диске» с выбором «Перечитать» / «Оставить моё»
- [ ] Файл удалён или переименован снаружи — пометить окно, следующее
      сохранение воссоздаёт файл
- [ ] `tauri-plugin-single-instance`: второй запуск не плодит процесс, а
      открывает новое окно в существующем
- [ ] Файл уже открыт — не дублировать окно, а поднять и сфокусировать
- [ ] Запоминание размера и позиции окна

**Готово, когда:** можно открыть три файла из проводника, править их
одновременно и не потерять ни байта при закрытии. И отдельно: запустить
программу без файла, создать документ, сохранить его под именем, закрыть,
открыть снова — содержимое на месте.

- [ ] Меню в стиле Блокнота: File, Edit, Format, View, Help
- [ ] Подменю `File ▸ New` со списком типов из того же реестра, что и
      стартовый экран
- [ ] Стартовый экран доводится до вида из спецификации: плитки с расширениями,

- [ ] Тип документа слева в строке состояния, клик открывает список смены типа
- [ ] Пометки `Read-only` и `Lossy` рядом с типом
- [ ] Контекстное меню по правой кнопке: над выделением — правка и
      форматирование, над пустым местом — вставить и выделить всё, над ссылкой
      — открыть и скопировать адрес. Штатное меню WebView2 отключается
- [ ] Строка состояния снизу справа:

      - с выделением: `Стр 11–16 · 42 слова · 310 знаков`

- [ ] `Ctrl+F` — поиск с подсветкой совпадений и счётчиком, `Enter` /
      `Shift+Enter` для перехода
- [ ] `Ctrl+H` — замена, включая «заменить всё»
- [ ] Регистр и «слово целиком» переключателями, регулярные выражения
- [ ] Полный список горячих клавиш сверен со [SPEC.md](docs/SPEC.md#горячие-клавиши)

**Готово, когда:** до любой функции можно добраться мышью и клавиатурой, не
зная разметки.

## M6 — Остальные форматы · 18 ч

Реализация по [docs/FORMATS.md](docs/FORMATS.md). Реестр и трейт уже есть с
M3 — эта веха наполняет их адаптерами. Фронтенд при этом не трогается: новые
типы сами появляются на стартовом экране, в меню `New` и в списке смены типа.

- [ ] Трейт `FormatAdapter` и диспетчер по расширению для всех типов
- [ ] Флаг `creatable` и заготовки: `{}` для JSON, каркас для HTML, пусто для
      остальных
- [ ] Простой текст: `.txt`, `.log`, `.ini`, `.env`, `.csv`, `.tsv` — правка без
      разметки, сохранение байт в байт
- [ ] Код и данные: `.json`, `.yaml`, `.toml`, `.xml`, `.html`, `.css`, `.js`,
      `.ts`, `.rs`, `.py` — подсветка, сохранение без изменений
- [ ] JSON: проверка синтаксиса, подсветка ошибки, команда «Отформатировать»
- [ ] Определение кодировки при открытии (UTF-8, UTF-8 BOM, UTF-16, CP1251),
      сохранение в исходной кодировке
- [ ] Нормализация переводов строк: файл с CRLF сохраняется с CRLF
- [ ] RTF: конвертация в Markdown при открытии, обратная конвертация
      подмножества при сохранении. Автосохранение выключено, первое сохранение
      предупреждает о потере оформления
- [ ] PDF: извлечение текста (`pdf-extract`), режим только для чтения,
      «Сохранить как Markdown»
- [ ] DOCX: то же через `docx-rs`
- [ ] Строка состояния показывает формат и режим: «Только чтение», «С потерями»

**Готово, когда:** ассоциация с любым из перечисленных расширений даёт
осмысленный результат, а не пустое окно. И: любой тип из стартового экрана
создаётся, сохраняется и переоткрывается без потерь, кроме RTF, который теряет
оформление честно и с предупреждением.

## Риски

| Риск | Оценка | Что делать |
| --- | --- | --- |
| Живой предпросмотр окажется сложнее ожидаемого | Высокая | M2 разбита на подвехи. Если M2.2 занимает больше 20 часов — урезать `%%комментарии%%` и вложенность до v1.1 |
| Курсор странно ведёт себя на скрытых маркерах | Высокая | Полагаться на `atomicRanges`, а не на собственную обработку клавиш |
| Обратная конвертация RTF теряет оформление | Средняя | Принято осознанно: автосохранение выключено, пользователь предупреждён |
| Извлечение текста из PDF даёт кашу на сложной вёрстке | Средняя | Режим только для чтения, честная пометка в строке состояния |
| Реестр форматов в M3 окажется мал для M6 | Средняя | Закладывать `FormatCapabilities` сразу целиком, даже с полями, которые до M6 не используются |
| Тормоза на файлах в мегабайты | Низкая | Декорации только в видимой области. Порог: выше 5 МБ предпросмотр отключается |
| SmartScreen блокирует неподписанный установщик | Точно случится | Либо сертификат, либо инструкция в заметках к релизу |
