# MarkNote

Быстрый Markdown-редактор для Windows. Дважды кликнул по `.md` — файл открылся;
из Проводника он маршрутизируется в свободное стартовое или новое окно, а
внутри окна документы можно держать во вкладках. Без хранилищ и плагинов, с окном настроек для
языка, редактора, предпросмотра, сохранения и окон.

Obsidian по ощущениям, Блокнот по весу.

---

## Зачем

Obsidian требует открыть приложение и открыть хранилище, чтобы прочитать один
файл. Блокнот открывает файл мгновенно, но показывает сырую разметку. MarkNote
делает и то и другое: живой предпросмотр Obsidian с временем запуска Блокнота.

## Что умеет (v1.0)

- **Живой предпросмотр.** Разметка скрыта, пока курсор не встал внутрь узла —
  тогда синтаксис раскрывается для правки. Никакого отдельного режима чтения.
- **Полный набор разметки:** `**жирный**`, `*курсив*`, `~~зачёркнутый~~`,
  `` `код` ``, `$математика$`, `%%комментарий%%`, `==подсветка==`, заголовки
  шести уровней, списки (маркированные, нумерованные, задачи), таблицы, цитаты,
  callout-блоки, сноски, горизонтальные линии, блоки кода, блоки формул,
  изображения.
- **Таблицы и изображения.** GFM-таблицы выравнивают колонки и скрывают строку
  разделителей в предпросмотре; `Tab` и `Shift+Tab` перемещают курсор по
  ячейкам. Относительные изображения разрешаются из папки документа, для
  недоступной картинки есть запасной вид.
- **Формулы.** KaTeX загружается только при первом появлении формулы, результат
  повторного рендера берётся из кэша.
- **Окна и вкладки.** Внутри окна вкладки переключают документы. Кнопка «+» и
  `Ctrl+T` создают вкладку со стартовым экраном; полоса вкладок появляется со
  всегда и показывает имя файла, формат и кнопку закрытия. Открытие
  файла из Проводника не добавляет вкладку: свободное стартовое окно
  переиспользуется, иначе создаётся новое, а повторное открытие уже открытого
  файла по умолчанию поднимает его окно; это поведение можно отключить в
  настройках окон.
- **Создание документов.** Стартовый экран и `File → New` используют общий
  реестр из 21 формата, 17 из них можно создать. Тип документа меняется из
  строки состояния без пересоздания редактора.
- **Сохранение.** `Save` и `Save as…` доступны в строке меню. Для обычных
  редактируемых файлов автосохранение срабатывает через 2 секунды после правки
  и при потере фокуса; запись атомарная. Если файл на диске изменился после
  открытия, приложение обнаруживает конфликт и не перезаписывает внешние
  изменения. При закрытии изменённого документа можно выбрать `Save`,
  `Discard` или `Cancel`.
- **Изменения на диске.** Чистый документ перезагружается с диска, а для
  изменённого доступны `Reload` и `Keep mine`. Если файл удалён снаружи,
  следующее сохранение воссоздаёт его.
- **Поиск и замена.** Панель поиска подключена к редактору; `Ctrl+F` и `Ctrl+H`
  открывают поиск и замену, есть счётчик совпадений, переход по результатам,
  настройки регистра, целого слова и регулярных выражений.
- **Другие форматы.** Подсветка синтаксиса для кодовых форматов загружается по
  требованию. JSON можно проверять и форматировать из контекстного меню. RTF
  редактируется с потерей части оформления, без автосохранения и с предупреждением;
  PDF, DOCX и EPUB открываются только для чтения и сохраняются как Markdown.
- **Интерфейс.** Меню `File`, `Edit`, `View`, `Help`, вкладки, стартовый экран,
  контекстное меню, выбор формата и уведомления подключены. Строка состояния
  показывает формат и счётчики документа. Масштаб меняет только текст редактора
  и сохраняется между запусками; справка содержит горячие клавиши, Markdown-
  справочник и сведения о программе. Язык интерфейса выбирается в окне настроек;
  документация — на русском.
- **Горячие клавиши.** Команды редактора и оболочки подключены к CodeMirror.
  Включая `Ctrl+G` для перехода к строке, они используют те же действия, что и
  меню. Приёмочные проверки перечислены в [ROADMAP.md](ROADMAP.md).
- **Настройки.** Окно настроек позволяет менять язык интерфейса, параметры
  редактора и предпросмотра, правила проверки орфографии и автозамены,
  сохранение и поведение окон.
- **Тёмная тема.** Единственная.

## Известные незавершённые части

- Вариант `Recent files` в настройках окон пока не имеет списка недавних файлов;
  до его реализации используйте `Start screen`.
- Сводное закрытие окна с несколькими изменёнными вкладками и окончательная
  приёмка наблюдения за изменениями файлов между вкладками ещё в работе.
- Для файлов больше 5 МБ предпросмотр отключается, но строка состояния пока не
  объясняет причину отключения.
- `Ctrl+0` одновременно назначен снятию заголовка и сбросу масштаба; поведение
  при конфликте требует отдельного решения.

Чего нет и не будет в v1.0: хранилищ, боковой панели с файлами, графа связей,
`[[вики-ссылок]]`, плагинов, синхронизации, светлой темы.

## Стек

| Слой | Выбор | Почему |
| --- | --- | --- |
| Оболочка | Tauri 2 | Нативное окно, WebView2 вместо своего Chromium; установщик 1.0.6 весит 3.1 МБ |
| Бэкенд | Rust | Файловые операции, конвертация форматов, наблюдение за диском |
| Фронтенд | Svelte 5 + TypeScript + Vite | Нет виртуального DOM и рантайма поверх редактора; вокруг CodeMirror нужна тонкая обвязка, а не фреймворк |
| Редактор | CodeMirror 6 | Единственный редактор, где живой предпросмотр делается штатно: декорации `Decoration.replace` прячут разметку, а плагин раскрывает её по позиции курсора. Monaco под это не гнётся |
| Разбор Markdown | `@lezer/markdown` | Инкрементальный парсер CodeMirror. Правит только изменённый участок дерева, поэтому предпросмотр не тормозит на длинных файлах |
| Формулы | KaTeX | Загружается лениво при первой формуле, повторные рендеры кэшируются |
| Установщик | NSIS + WebView2 bootstrapper | Установка без прав администратора, ассоциации файлов, Windows 10 и 11 |

Подробное обоснование — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Требования для разработки

- Windows 10 (1809+) или Windows 11
- [Rust](https://rustup.rs) stable
- [Node.js](https://nodejs.org) 20 LTS или новее
- Visual Studio Build Tools с компонентом «Разработка классических приложений на C++»
- WebView2 Runtime (в Windows 11 предустановлен)

## Запуск

```bash
npm install
npm run tauri dev
```

Сборка установщика:

```bash
npm run tauri build
```

Измеренный установщик: `MarkNote_1.0.6_x64-setup.exe`, 3.1 МБ (исполняемый файл 6.9 МБ).

## Структура репозитория

```
marknote/
├─ .github/
│  └─ workflows/release.yml  сборка релиза по тегу
├─ docs/
│  ├─ SPEC.md           поведение до мелочей: что происходит на каждое действие
│  ├─ ARCHITECTURE.md   модули, IPC, поток данных, решения и их причины
│  ├─ FORMATS.md        таблица форматов и правила сохранения
│  ├─ CONTRACTS.md      контракты между параллельными модулями
│  ├─ SETTINGS.md       состав и значения настроек
│  └─ AUDIT.md          сверка реализации со спецификацией
├─ fixtures/            файлы для тестов кодировок, разметки и производительности
├─ qa/                  приёмочные сценарии, журналы, отчёты и снимки
├─ scripts/             скрипты и заметки релиза
├─ src/                 фронтенд (Svelte + CodeMirror)
│  ├─ editor/           расширения CodeMirror, `zoom.ts`, живой предпросмотр
│  │  └─ livePreview/   построители декораций и виджеты
│  ├─ state/             состояние документов и вкладок, форматы, автосохранение
│  ├─ ui/                меню, вкладки, стартовый экран, строка состояния, поиск
│  └─ styles/           токены темы
├─ src-tauri/           бэкенд (Rust)
│  └─ src/
│     ├─ formats/       адаптеры форматов
│     ├─ messages.rs    сообщения интерфейса и ошибок
│     ├─ watcher.rs     наблюдение за изменениями на диске
│     └─ windows.rs     управление окнами, маршрутизация открытия файлов
├─ tests/                тесты редактора, состояния и UI
│  └─ wiring/           проверки связности приложения и экспортов
├─ ROADMAP.md
└─ README.md
```
