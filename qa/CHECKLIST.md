# Ручной чек-лист приёмочного тестирования MarkNote

Этот документ содержит сценарии и проверки, которые требуют визуального или интерактивного участия человека (поведение фокуса, физическое перемещение курсора, контекстные меню, физический рендеринг формул и анимаций).

---

## Веха M0 — Скелет и запуск

- [ ] **M0.1 — Тёмная тема окна при запуске**
  - *Действие:* Запустить `marknote.exe`.
  - *Ожидаемый результат:* Окно открывается сразу с тёмным заголовком (`DWMWA_USE_IMMERSIVE_DARK_MODE`), тёмным фоном `#1e1e1e` без белых вспышек при инициализации.
- [ ] **M0.2 — Открытие файла из Проводника / CLI**
  - *Действие:* Перетащить `.md` файл на ярлык `marknote.exe` или выполнить `marknote.exe fixtures\showcase.md`.
  - *Ожидаемый результат:* В окне сразу отображается содержимое файла, а заголовок окна имеет вид `showcase.md — MarkNote`.

## Веха M1 — Ядро редактора

- [ ] **M1.1 — Мягкий перенос строк (Line Wrapping)**
  - *Действие:* Вставить длинный абзац текста (более 150 символов без переводов строк).
  - *Ожидаемый результат:* Текст плавно переносится по границе колонки `81ch` по центру окна. В файл на диск жесткие переносы `\n` не добавляются.
- [ ] **M1.2 — История отмены и повтора (Undo/Redo)**
  - *Действие:* Набрать текст, нажать `Ctrl+Z`, затем `Ctrl+Y` или `Ctrl+Shift+Z`.
  - *Ожидаемый результат:* Правка отменяется и восстанавливается корректно. Глубина истории не ограничена.
- [ ] **M1.3 — Поведение клавиши Tab**
  - *Действие 1:* Нажать `Tab` в обычном тексте -> вставляются 4 пробела.
  - *Действие 2:* Нажать `Tab` на пункте списка -> пункт смещается вправо (вложенность +1 уровень).
  - *Действие 3:* Нажать `Shift+Tab` на вложенном пункте -> пункт смещается влево (-1 уровень).
- [ ] **M1.4 — Клавиша Enter в списках**
  - *Действие:* Нажать `Enter` в конце заполненного пункта списка -> создаётся новый пункт с тем же маркером/номером. Нажать `Enter` на пустом пункте списка -> маркер удаляется, происходит выход из списка.
- [ ] **M1.5 — Автопарность и оборачивание выделения**
  - *Действие 1:* Ввести `*`, `` ` ``, `[`, `(`, `==`, `~~` -> автоматически вставляется закрывающий символ.
  - *Действие 2:* Выделить слово и нажать `Ctrl+B`, `Ctrl+I` или `Ctrl+E` -> слово оборачивается в разметку; повторное нажатие снимает разметку.

## Веха M2 — Живой предпросмотр (Live Preview)

- [ ] **M2.1 — Скрытие и раскрытие разметки под курсором**
  - *Действие:* Набрать `**жирный текст**` и увести курсор на другую строку.
  - *Ожидаемый результат:* Маркеры `**` исчезают, текст отображается жирным начертанием. При возвращении курсора стрелками внутрь слова маркеры `**` снова проявляются для редактирования.
- [ ] **M2.2 — Атомарность скрытых маркеров (курсор не застревает)**
  - *Действие:* Перемещать курсор стрелками `←` и `→` через границы скрытого форматирования (`**`, `*`, `==`, `~~`).
  - *Ожидаемый результат:* Курсор не застревает в невидимых символах разметки; нажатия `Home`, `End`, `Ctrl+←`, `Ctrl+→` перемещают курсор естественно, как в обычном тексте.
- [ ] **M2.3 — Строчные стили разметки**
  - [ ] `*курсив*` — наклонный шрифт без звездочек снаружи.
  - [ ] `~~зачёркнутый~~` — перечёркнутый текст.
  - [ ] `==подсветка==` — жёлтый полупрозрачный фон (`var(--text-highlight-bg)`).
  - [ ] `` `код` `` — моноширинный шрифт и подложка.
  - [ ] `%%комментарий%%` — приглушённый цвет текста, скрывается целиком при уходе курсора.
  - [ ] Ссылки `[текст](url)` — отображается только `текст`. При `Ctrl+клик` ссылка открывается во внешнем браузере по умолчанию.
- [ ] **M2.4 — Заголовки шести уровней (# - ######)**
  - *Действие:* Ввести заголовки от `# ` до `###### `.
  - *Ожидаемый результат:* Решётки скрываются, когда курсор вне строки. Размер и вес шрифта соответствуют шкале Obsidian (H1 крупный жирный, H6 приглушённый).
- [ ] **M2.5 — Чекбоксы задач (- [ ] / - [x])**
  - *Действие:* Кликнуть мышью по квадратному чекбоксу задачи.
  - *Ожидаемый результат:* Чекбокс переключает состояние между выполненным и невыполненным прямо в документе (текст меняется на `- [x]`); выполненный пункт становится приглушённым и зачёркнутым; действие можно отменить через `Ctrl+Z`.

## Веха M3 — Файлы, сохранение и наблюдение за диском

- [ ] **M3.1 — Автосохранение через 2 секунды простоя**
  - *Действие:* Изменить текст в ранее сохранённом файле и прекратить ввод.
  - *Ожидаемый результат:* В строке меню статус меняется с `Unsaved` на `Saving…`, затем через 2 секунды на `Saved <время>`. Файл на диске обновляется без нажатия `Ctrl+S`.
- [ ] **M3.2 — Автосохранение при потере фокуса**
  - *Действие:* Внести правку и сразу переключиться на другое окно (Alt+Tab).
  - *Ожидаемый результат:* Файл немедленно записывается на диск, статус переходит в `Saved`.
- [ ] **M3.3 — Предупреждение при закрытии с несохранёнными изменениями**
  - *Действие:* Создать новый документ без пути, ввести `unsaved check`, затем нажать крестик закрытия окна `✕`.
  - *Ожидаемый результат:* Появляется диалог `Save changes?` с кнопками `Save`, `Discard` и `Cancel`; текст не исчезает до выбора действия.
  - *Проверка Cancel:* Нажать `Cancel` — диалог закрывается, окно и текст остаются.
  - *Проверка Discard:* Повторить закрытие и нажать `Discard` — окно закрывается без сохранения.
  - *Проверка Save:* Создать ещё один новый документ, ввести текст и выбрать `Save` — открывается выбор места и имени файла; после сохранения документ закрывается штатно.
- [ ] **M3.4 — Реакция на изменение файла на диске сторонней программой**
  - *Сценарий 1 (Буфер чистый):* Изменить файл через `notepad.exe` и сохранить -> в MarkNote текст тихо обновляется с сохранением позиции курсора и скролла.
  - *Сценарий 2 (Буфер изменён):* Внести правку в MarkNote (не сохранённую) и изменить файл снаружи -> сверху появляется плашка `File changed on disk` с кнопками `Reload` и `Keep mine`.
  - *Сценарий 3 (Файл удалён):* Удалить файл на диске -> появляется плашка `File no longer exists`.

## Веха M4 — Блочные элементы

- [ ] **M4.1 — Таблицы GFM**
  - *Действие:* Открыть или создать Markdown-таблицу `| Col 1 | Col 2 |`.
  - *Ожидаемый результат:* Таблица визуально выравнивается по колонкам; нажатие `Tab` внутри ячейки переводит курсор в следующую ячейку таблицы; маркеры `|` и `-` скрываются в режиме просмотра.
- [ ] **M4.2 — Callout-блоки (> [!NOTE])**
  - *Действие:* Вставить блок `> [!NOTE]` или `> [!WARNING]`.
  - *Ожидаемый результат:* Рисуется цветная плашка с левой акцентной полосой, иконкой и заголовком. При курсоре вне блока стрелка цитаты `>` скрыта.
- [ ] **M4.3 — Математические формулы KaTeX ($ и $$)**
  - *Действие:* Вставить inline-формулу `$E = mc^2$` и блок `$$\int_0^\infty x dx$$`.
  - *Ожидаемый результат:* KaTeX синхронно отрисовывает типографическую формулу без мерцания. При клике внутрь формулы раскрывается исходный TeX-текст для редактирования.
- [ ] **M4.4 — Изображения (![alt](path))**
  - *Действие:* Вставить изображение относительно папки документа `![Скриншот](image.png)`.
  - *Ожидаемый результат:* Картинка отображается внутри колонки текста. При битом пути отображается аккуратная рамка с именем файла, а не пустота или сбой.

## Веха M5 — Обвязка интерфейса, меню, поиск

- [ ] **M5.1 — Поиск и замена (Ctrl+F / Ctrl+H)**
  - *Действие 1:* Нажать `Ctrl+F` -> в правом верхнем углу плавно открывается панель поиска.
  - *Действие 2:* Ввести поисковый запрос -> все совпадения подсвечиваются оранжевым, текущее совпадение ярче, счётчик показывает `X of Y`.
  - *Действие 3:* Нажатие `Enter` переходит к следующему совпадению, `Shift+Enter` — к предыдущему.
  - *Действие 4:* Нажать `Ctrl+H` -> раскрывается поле замены и кнопки `Replace` / `Replace All`.
  - *Действие 5:* Нажать `Escape` -> панель закрывается, фокус немедленно возвращается в редактор.
  - *Действие 6:* Ввести некорректное регулярное выражение (например `(` при включенном `.*`) -> поле подсвечивается красным, приложение не падает, пишется понятное сообщение об ошибке.
- [ ] **M5.2 — Главное меню (File, Edit, Format, View, Help)**
  - *Действие:* Кликнуть по пунктам главного меню в шапке.
  - *Ожидаемый результат:* Открываются выпадающие меню в нативном стиле Windows/Obsidian, работают горячие клавиши, продублированные в меню.
- [ ] **M5.3 — Контекстное меню по правой кнопке мыши**
  - *Действие 1 (над текстом):* Кликнуть правой кнопкой мыши -> открывается стилизованное контекстное меню MarkNote (`Cut`, `Copy`, `Paste`, `Bold`, `Italic` и т.д.). Штатное меню WebView2 отключено.
  - *Действие 2 (над ссылкой):* `Open Link`, `Copy Link Address`.
- [ ] **M5.4 — Строка состояния (Status Bar)**
  - *Действие:* Выделить фрагмент текста.
  - *Ожидаемый результат:* Слева отображается формат (например `Markdown`), справа — `Ln X, Col Y · Z lines · W words · C chars`. При выделении отображается счётчик строк и слов только для выделенного фрагмента (слова считаются только целые).
- [ ] **M5.5 — Стартовый экран**
  - *Действие:* Запустить MarkNote без файла при пустом буфере.
  - *Ожидаемый результат:* Показывается экран `New file` с плитками форматов Markdown, Plain Text, JSON, YAML, TOML и CSV, а также пунктом `More…`; редкие форматы появляются после нажатия `More…`. Выбор плитки открывает пустой документ выбранного типа.

- [ ] **M5.6 — Смена типа документа из строки состояния**
  - *Действие:* Создать документ Markdown, ввести `before middle after`, поставить курсор между словами, добавить `X`, затем щёлкнуть по типу `Markdown` слева в строке состояния и выбрать `JSON`.
  - *Ожидаемый результат:* Текст остаётся на месте, курсор остаётся после `X`, заголовок меняется с `Untitled.md — MarkNote` на `Untitled.json — MarkNote`. Нажать `Ctrl+Z` — удаляется только `X`; нажать `Ctrl+Y` — `X` возвращается. Если текст, позиция курсора или история отмены сбросились, проверка не пройдена.

- [ ] **M5.7 — Файловые горячие клавиши при фокусе в редакторе**
  - *Действие 1 (`Ctrl+S`):* Открыть временную копию текстового файла, изменить строку, оставить фокус в тексте и нажать `Ctrl+S`.
  - *Ожидаемый результат:* Изменение записано в этот файл; проверить его содержимое в Блокноте. Сочетание не должно открывать меню или менять документ.
  - *Действие 2 (`Ctrl+O`):* Вернуться в MarkNote, щёлкнуть по тексту и нажать `Ctrl+O`; в диалоге выбрать `fixtures\showcase.md`.
  - *Ожидаемый результат:* Диалог открытия появляется, а после выбора отображается `showcase.md` с соответствующим заголовком окна.
  - *Действие 3 (`Ctrl+N`):* При фокусе в тексте нажать `Ctrl+N`.
  - *Ожидаемый результат:* Создаётся новый пустой документ; открытый несохранённый текст не исчезает без предупреждения.
  - *Действие 4 (`Ctrl+W`):* Сохранить или отменить изменения, щёлкнуть по тексту и нажать `Ctrl+W`.
  - *Ожидаемый результат:* Закрывается активное окно; если документ изменён, сначала появляется `Save changes?` с кнопками `Save`, `Discard` и `Cancel`.

- [ ] **M5.8 — Заголовок после создания и сохранения как**
  - *Действие 1:* С открытым документом нажать `Ctrl+N` и, если потребуется, выбрать Markdown.
  - *Ожидаемый результат:* Заголовок нового документа показывает `Untitled.md — MarkNote`, а не имя предыдущего файла.
  - *Действие 2:* Для нового документа вызвать `Save As…` из меню `File` и сохранить его под временным именем `title-check.md`.
  - *Ожидаемый результат:* После сохранения заголовок меняется на `title-check.md — MarkNote`.

- [ ] **M5.9 — Масштаб текста и его сохранение**
  - *Действие:* Открыть документ, нажать `Ctrl`+`+` несколько раз, затем `Ctrl`+`-` и `Ctrl`+`0`.
  - *Ожидаемый результат:* Текст редактора увеличивается, уменьшается и возвращается к исходному масштабу соответственно.
  - *Проверка перезапуска:* Установить отличный от исходного масштаб, закрыть приложение и открыть его снова.
  - *Ожидаемый результат:* Выбранный масштаб сохранён после перезапуска; `Ctrl`+`0` возвращает исходный.

- [ ] **M5.10 — Разделы справки в меню Help**
  - *Действие:* Открыть меню `Help` и по очереди выбрать `Keyboard Shortcuts`, `Markdown Reference` и `About`.
  - *Ожидаемый результат:* Каждый пункт открывает соответствующую справку/информацию, содержимое видно и читаемо; закрытие одного раздела позволяет открыть другой, приложение остаётся работоспособным.

## Веха M6 — Другие форматы

- [ ] **M6.1 — Кодировка CP1251 (Windows-1251)**
  - *Действие:* Открыть `fixtures\cp1251.txt`.
  - *Ожидаемый результат:* Русский текст отображается без кракозябр. При сохранении файл остаётся в кодировке CP1251.
- [ ] **M6.2 — Нормализация окончаний строк (CRLF / LF)**
  - *Действие:* Открыть `fixtures\crlf.md`, внести правку и сохранить.
  - *Ожидаемый результат:* Окончания строк сохраняются как `\r\n`, не превращаясь в `\n`.
- [ ] **M6.3 — Подсветка файлов кода и конфигураций**
  - *Действие:* Открыть файл `.json`, `.yaml` или `.toml`.
  - *Ожидаемый результат:* Разметка Markdown для них отключена, но активна соответствующая подсветка синтаксиса кода.

- [ ] **M6.4 — Отказ для двоичного файла**
  - *Действие:* Через `File → Open…` выбрать `fixtures\logo.png`.
  - *Ожидаемый результат:* MarkNote показывает понятное сообщение, что двоичный файл нельзя открыть как текст; содержимое не превращается в нечитаемые символы, приложение остаётся открытым.
